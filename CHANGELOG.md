## [1.0.0] - 2026-04-24

### Added
- Initial release of Airaa Design System
- Design tokens system (colors, typography, spacing, border radius)
- Atomic design component structure
- Core components:
  - Button component with variants (primary, secondary, outline, ghost) and sizes
  - Input component with label, error states, and helper text
  - Card component with elevation and padding options
- TypeScript support with full type definitions
- CSS custom properties for all design tokens
- Comprehensive documentation (README, Getting Started, Tokens guide)
- Example implementations
- MIT License
- Contributing guidelines

### Token Categories
- **Colors**: Primary, neutral, and semantic color scales
- **Typography**: Font families, sizes, weights, and line heights
- **Spacing**: Consistent spacing scale based on 4px base unit
- **Border Radius**: Radius scale from none to full pill shape
